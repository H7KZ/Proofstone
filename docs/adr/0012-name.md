# ADR-0012: The project is named Proofstone

- Status: Accepted
- Date: 2026-11-03 (revised the same day; the working name was "Testificate")
- Deciders: maintainer

## Context
The name must:
- put the project's main value, **trustworthy results**, first;
- read naturally to developers both inside and outside Minecraft;
- avoid the "Minecraft" trademark, since Mojang's brand guidelines don't allow it in product names;
- be short and searchable, without colliding with existing projects;
- follow the maintainer's PascalCase convention for GitHub repositories.

## Decision
The project is named **Proofstone**. The repository is `H7KZ/Proofstone`.
- **proof** means verified, as in "bulletproof". It reflects the dual oracle and self-test design.
- **-stone** follows Minecraft's naming pattern for special blocks, such as redstone, glowstone and
  lodestone.
- The name echoes the *touchstone*, the stone historically used to test the purity of gold.

## Collision check (2026-11-03)
- **GitHub:** 4 repositories, all with 0 stars and unrelated (a math project, a portfolio tool and two
  others). A user named `proofstone` exists, with an unrelated site, `proofstone.dev`. The organisation
  name `ProofstoneMC` is free.
- **Maven Central:** no artefacts.
- **npm:** `proofstone` is free.

## Naming conventions
| Thing | Form |
|---|---|
| GitHub repository | `Proofstone` (PascalCase) |
| Gradle modules and artefact IDs | `proofstone-api`, `proofstone-core`, `proofstone-protocol` (kebab-case, the Maven convention) |
| Java packages | `dev.proofstone.*` if a domain is acquired, otherwise `io.github.h7kz.proofstone.*`. Decided in T-M6-01. |
| Maven group | `io.github.h7kz.proofstone` (verify the namespace on Central in T-M6-01) |
| Images | `ghcr.io/h7kz/proofstone-*` |
| Annotation | `@Proofstone` |
| System properties and environment variables | `-Dproofstone.*`, `PROOFSTONE_*` |

## Alternatives considered
- **Testificate**, the early internal name of Minecraft villagers. It says "test", but only Minecraft
  insiders get the reference, and it can be misread as a pun. An npm package and a GitHub user already
  use the name.
- **SculkSensor**, the block that detects vibrations. It says "detect" rather than "prove", it is long,
  and it uses a Mojang block name directly.
- **Spyglass** collides with SpyglassMC (478 stars), a Minecraft data-pack tooling project.
- **TrialChamber** would be confused with the Minecraft structure and the existing plugins named after it.
- **Touchstone and Assay** have heavy collisions (touchstonejs, Rust and JS projects).
- **Crucible, Anvil, Lodestone and Tripwire** are taken by existing Minecraft projects or well-known
  tools: a hybrid server, the world format, LodestoneLib and the Tripwire security tool.
- **Observer and Comparator** are too generic, and `Comparator` clashes with a Java interface.
