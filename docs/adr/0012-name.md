# ADR-0012: Project name is Testificate

- Status: Accepted
- Date: 2026-11-03

## Context
The name must:
- signal testing;
- be recognisable to the Minecraft community;
- avoid the "Minecraft" trademark, which Mojang's brand guidelines don't allow in product names;
- be short and searchable;
- not collide with existing projects.

## Decision
The name is **Testificate**. It was the internal name of villagers in early Minecraft development and
still appears in game code. Villagers were, literally, the game's test subjects.

## Collision check (2026-11-03)
- GitHub: one Python testing repo with 1 star, plus a few empty repos. The user `testificate` is taken;
  the org `testificatemc` is free.
- Maven Central: no artefacts named `testificate`.
- npm: `testificate` exists (empty description, last modified 2022). Use the scope `@testificatemc/*`
  if npm packages are ever needed.

## Coordinates (planned)
- Maven: `io.github.h7kz.testificate:*` (verify the namespace on Central), or `dev.testificate:*` if a
  domain is acquired.
- Images: `ghcr.io/h7kz/testificate-*`.

## Alternatives considered
- **Touchstone:** a stone used to test gold. Too many collisions (touchstonejs and others).
- **Assay:** testing ore purity. Collides with Rust and JS testing projects.
- **Crucible:** an existing Minecraft hybrid server. Rejected.
- **Anvil:** collides with the Anvil world format. Rejected.
- **Observer, Comparator:** Minecraft blocks, but `Comparator` clashes with Java's interface. Rejected.
- **Allay:** AllayMC, a Bedrock server. Rejected.
