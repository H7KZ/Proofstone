# Getting help

| You want | Go to |
|---|---|
| To write your first test | [Gradle quickstart](docs/user/quickstart-gradle.md) or [Maven quickstart](docs/user/quickstart-maven.md) |
| To understand a verdict or an error | [Troubleshooting](docs/user/troubleshooting.md) |
| Answers to common questions | [FAQ](docs/faq.md) |
| To know what is and is not supported | [Platforms](docs/platforms.md) and [limits](docs/limits.md) |
| To report a bug | [Open a bug report](https://github.com/H7KZ/Proofstone/issues/new?template=bug.yml) with the repro bundle |
| To report a security problem | [SECURITY.md](SECURITY.md), never a public issue |
| To propose a feature or platform | [Open a feature request](https://github.com/H7KZ/Proofstone/issues/new?template=feature.yml) |

There is no paid support and no chat server. Maintainers answer issues on a best-effort basis.
